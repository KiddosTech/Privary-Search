## 📖 About

**Privary** is an independent, privacy-focused meta search engine that combines results from DuckDuckGo and SearXNG to provide comprehensive search results without tracking your data. 

Built with ❤️ by **Ahmad Ilham Kurniawan** ([KiddosTech](https://github.com/KiddosTech))

### Why Privary?

- 🔒 **Zero Tracking** - No cookies, no logs, no personal data collection
- 🦆 **DuckDuckGo Backend** - Reliable, privacy-respecting search results
- 🌐 **SearXNG Fallback** - Google-quality results when needed
- ♾️ **Unlimited** - No API keys, no rate limits, no quotas
- 🆓 **100% Free** - Open source, free forever
- 🎯 **Multi-Type Search** - Web, Images, Videos, News

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🔍 **Web Search** | Full web search with titles, URLs, and descriptions |
| 🖼️ **Image Search** | Find images with thumbnails and direct links |
| 🎬 **Video Search** | Search videos across multiple platforms |
| 📰 **News Search** | Latest news from various sources |
| 💡 **Suggestions** | Real-time search suggestions as you type |
| 🎯 **PrivaryRank™** | Proprietary ranking algorithm for better results |
| 🛡️ **PrivaryShield™** | Privacy protection layer |
| 📱 **Responsive** | Works on desktop, tablet, and mobile |
| 🌙 **Dark Mode** | Beautiful dark theme by default |

## 📦 Installation

### Prerequisites
- [Node.js](https://nodejs.org) v18 or higher
- [npm](https://www.npmjs.com) (comes with Node.js)

### Quick Start

```bash
# Clone the repository
git clone https://github.com/KiddosTech/privary-search.git

# Navigate to project folder
cd privary-search

# Install dependencies
npm install

# Start the server
npm start
